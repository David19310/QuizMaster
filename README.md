# QuizMaster

QuizMaster este o aplicație educațională cu quiz-uri și provocări, creată pentru elevi.

## Public țintă
Aplicația este destinată elevilor din clasa a XI-a și celor care vor să învețe prin jocuri interactive.

## Cum se joacă?
- Utilizatorul alege o categorie.
- Răspunde la întrebările quiz-ului.
- Acumulează puncte în funcție de răspunsuri.
- La final își poate verifica scorul.
